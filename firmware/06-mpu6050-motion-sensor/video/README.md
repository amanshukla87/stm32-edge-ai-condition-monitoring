# MPU6050 Motion Sensor Videos

Videos documenting the STM32 NUCLEO-F446RE MPU6050 motion-sensor integration and testing.

## Videos

- `stm32-mpu6050-tilt-test.mp4` — physical MPU6050 motion/tilt test with the STM32 multisensor setup.
- `stm32-complete-hardware-demo.mp4` — complete STM32 multisensor hardware demonstration.

The tilt-test video shows the hardware being moved in different directions while the MPU6050 sensor data is monitored.
