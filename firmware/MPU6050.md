# MPU6050 Hardware Bring-Up

## Purpose

The MPU6050 is used in the STM32 condition-monitoring project to acquire accelerometer and gyroscope data for motion and vibration analysis.

## I2C

The tested MPU6050 module responds at:

```text
0x68
```

## STM32 Connection

The planned STM32 connection uses the project's I2C interface:

| MPU6050 | STM32 NUCLEO-F446RE |
|---|---|
| VCC | Sensor supply according to the module used |
| GND | GND |
| SCL | I2C SCL |
| SDA | I2C SDA |

Use the exact board/module supply requirements during hardware testing.

## Bring-Up Sequence

1. Verify sensor power and common ground.
2. Check the I2C wiring.
3. Scan the I2C bus and confirm address **0x68**.
4. Read the MPU6050 identity/register response.
5. Configure accelerometer and gyroscope registers.
6. Read accelerometer, gyroscope, and temperature registers.
7. Print or display values for verification.
8. Integrate the readings into the multisensor monitoring firmware.

## Debugging Note

An earlier STM32 test produced no valid MPU6050 response. The sensor was then checked separately with an Arduino UNO, where the module responded at **0x68** and returned accelerometer, gyroscope, and temperature values.

This confirms that the sensor module can communicate and provides a known-good reference for retesting the STM32 hardware path.
