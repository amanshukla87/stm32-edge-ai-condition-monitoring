# DS18B20 Temperature Sensor Schematic

This directory contains the KiCad schematic files for the STM32-based DS18B20 temperature-sensor interface.

## Files

Add the following files here:

- `stm32-ds18b20-temperature-interface.kicad_sch` — editable KiCad schematic
- `stm32-ds18b20-temperature-interface.pdf` — exported schematic for quick viewing on GitHub
- `stm32-ds18b20-temperature-interface.png` — optional schematic preview

Only include files that are available and match the actual circuit. Check the schematic's pin connections and power requirements before using it as a wiring reference.
