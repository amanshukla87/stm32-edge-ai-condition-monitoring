# TFT Display Images

Store photos and screenshots related to Stage 09 — TFT Display here.

Suggested contents:
- TFT module and wiring photos
- STM32CubeIDE configuration screenshots
- Display test results (red, green, blue, white, and black)
- Troubleshooting photos showing the actual screen behaviour

Use descriptive filenames and add a short note describing each image. GitHub does not preserve empty folders, so this README keeps the `images` folder in the repository.
