# Website Source Code

Keep the website's source code in this folder as the project grows.

Suggested files:
- `style.css` — website layout, colours, and responsive styling.
- `script.js` — dashboard interactions, charts, and data-handling logic.
- Additional JavaScript or CSS files when they have a clear purpose.

The main entry page currently lives at `website/index.html`. If CSS or JavaScript files are moved or added here, update the paths in `index.html` accordingly.

**Note:** Dashboard readings and alerts are demonstration data until the hardware data connection is implemented and tested.
