# Website Screenshots and Images

Use this folder for the website's design references, dashboard screenshots, and project-related images intended for the website.

Suggested organisation:
- `references/` — screenshots used as design inspiration.
- `screenshots/` — screenshots of the website during development.
- `diagrams/` — approved system or dashboard diagrams.

Use clear filenames, for example `dashboard-overview.png` or `sensor-panel-reference.jpg`. Add the actual image files to the repository; this README only documents the folder.

Only describe displayed sensor readings as live data after the hardware connection is implemented and verified.
